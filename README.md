# alphazoo

Implements https://arxiv.org/pdf/2505.11122 on FTSE250
Any work done using coding agents (chatgpt) will be noted as such in the commit message

## Implementation Details
Trained from 2020-01-01 to 2024-12-31, validated 2025-01-01 to 2026-07-01.\
Did not use Frequent Subtree Avoidance (FSA) from original paper, relied on diversity metric.\
Built 201 zoo members using Z-AI's GLM5.3 Flash as the underlying LLM. \
**NB**: Strong bias in the data coming from decision to train and validate on stocks that
1. Were listed on the LSE over the entire train/test period 
2. Were present in the FTSE250 on 2026-09-21
3. Had a full trading history over the train/test period on every LSE trading day.

In future, one would redesign backtester and data gathering to account for this bias. This bias also rules out using the current implementation for real trading.\
0.15% transaction costs assigned to each trade for portfolio backtesting.

## Results
Selecting top 10/50/100/200 alphas from zoo by RankICIR:
- Ridge regression achieved RankIC of 0.0036/-0.0009/-0.0022/0.0043, AER 16.68%/12.04%/12.89%/14.73%
- Simple mean of top alphas achieved RankIC of 0.0064/0.0072/0.0063/0.0049, AER 20.21%/17.83%/12.68%/17.44%
- MLP regression achieved RankIC of -0.0029/-0.0006/0.0015/0.0175, AER 12.88%/23.70%/13.01%/13.81%
- LightGBM regression achieved RankIC of -0.0014/0.0165/0.0012/0.0126, AER: 10.43%/14.54%/8.50%/9.16%
- Biased (see Implementation Details) AER of FTSE250 over test period: 15.27%

In this implementation, out-of-sample correlation performance falls far short of the values suggested by the original paper, while portfolio performance looks similarly unstable, indicating there is no evidence it can predict FTSE250 stock movements in general. 

## Design
Backtest of each alpha along 5 dimensions mentioned in original paper:
1. Effectiveness - RankIC
2. Stability - RankICIR
3. Turnover - Percentage change in simple top 10% allocation based on formula
4. Diversity - Maximum correlation with alpha already in zoo
5. Overfitting Risk - Determined by LLM judgement

<!-- end of the list -->

Backtest, MCTS search and final portfolio generation all written from scratch (no QLib as used in original paper).\
Predictive formulas trained with:
- sklearn Ridge
- torch MLP
- LightGBM
Portfolio built by attempting to hold top 24 predicted stocks, changing at most 6 a day to reduce turnover.\
Initial 10 alphas were generated by Gemini 3.5 Flash Lite without improvement to produce baseline alpha zoo for relative rankings used to guide later searches. Further 10 were also generated by Gemini, as it had greater token generation speed and was more concise when prototyping the first 10 searches.\
Uses Openrouter key in `.env` file to access Openrouter API via Client SDK.
